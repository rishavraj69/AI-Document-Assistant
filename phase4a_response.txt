Embedding model chosen
- sentence-transformers/all-MiniLM-L6-v2

Why this model
- lightweight enough for local development,
- reliable for semantic similarity tasks,
- commonly used for simple RAG-style document search.

What an embedding represents
An embedding is a numerical vector that captures the semantic meaning of a chunk of text.

In simple terms:
- chunks with similar meaning end up closer together in vector space,
- this is what later phases will use for semantic retrieval and similarity search.

How to test /test-embeddings in Swagger
1. Start the backend with the command above.
2. Open: http://127.0.0.1:8000/docs
3. Find: POST /test-embeddings
4. Click Try it out
5. Upload a PDF
6. Click Execute

You should receive JSON like:
{
  "filename": "example.pdf",
  "total_chunks": 6,
  "embedding_dimension": 384,
  "chunks": [
    {
      "page_number": 1,
      "source_filename": "example.pdf",
      "preview": "Some chunk text...",
      "embedding_preview": [0.123, -0.456, 0.789, ...]
    }
  ]
}

This lets you verify that:
- chunks were generated,
- embeddings were created,
- metadata (page_number, source_filename) is preserved,
- the embedding vectors are being produced in a lightweight preview form.
